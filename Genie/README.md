# Genie: Your Personal Assistant Workspace

Welcome home, Pop! This directory is where I live and work as your personal assistant. 

## How We Work Together
I can help you with a variety of tasks using this folder structure:

1. **Tasks (`/tasks/index.md`)**: You can ask me to add tasks here, or you can add them yourself. When you ask me what's on your plate, I'll check here first.
2. **Notes (`/notes/daily_log.md`)**: Ask me to jot down thoughts, ideas, or meeting notes. I can also help summarize these for you later.
3. **Research (`/research/`)**: Need to know about a topic? Ask me to search the web and I'll drop a beautifully formatted summary right into the research folder using the templates we've set up.
4. **Personal Knowledge Base (`/pop_knowledge.md`)**: This is my long-term memory about your preferences, work style, and goals. It helps me assist you better every day.

## Getting Started
To interact with me, just open the chat UI and ask:
- "Genie, what do I have to do today?"
- "Genie, research the latest trends in AI and put a summary in my folder."
- "Genie, add a note to my daily log that I had a great idea for a new app."

I'm ready whenever you are!
