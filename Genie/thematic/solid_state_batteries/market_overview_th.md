# ภาพรวมตลาด

มูลค่าตลาดของแบตเตอรี่แบบ Solid State คาดว่าจะเติบโตอย่างรวดเร็วเมื่อรถยนต์ไฟฟ้าเปลี่ยนผ่านไปสู่การใช้พลังงานยุคใหม่ ขนาดตลาดอาจสูงถึง 15,000 ล้านดอลลาร์สหรัฐภายในปี 2030
